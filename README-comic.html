Part 2: How it works

A Live ISO already holds a finished, ready-to-run system. BoomBox lifts that system out and hands it to WSL2, so the installer never needs to run.

The journey from ISO to OS

ISOWindows mounts it as a drive
HelperTiny Alpine Linux merges the OS layers
StreamFiles flow straight through, with no temp copy
ext4.vhdx
Your folderThe OS lands on its own virtual disk

What happens in those 4 minutes

  1. Windows opens the ISO as a temporary drive.
  2. The helper finds the OS image: live/filesystem.squashfs, or casper/ layers on Ubuntu.
  3. The OS's own tar packs every file and keeps its permissions.
  4. That stream feeds wsl --import, which writes a hidden disk in .boombox\.
  5. The ISO closes and the helper shuts down.

Then it skips the setup

  1. Creates your user with passwordless sudo.
  2. Turns off the C: drive, Windows programs and the Windows PATH.
  3. Connects only your folder, at /box.
  4. Removes leftovers from DVD booting, such as the cdrom package source.
  5. Disables services that need real hardware, then starts clean.

Part 3: Powers and weaknesses

Every hero has a weakness. Read this one before testing anything risky.

Powers

  • Each box has its own files, packages, users, services and hostname.
  • Apps inside can't see C: or run Windows programs by default.
  • apt, systemd, networking and tools like nmap run for real.
  • Delete wipes the Linux system and keeps the files in your folder.
DANGER!

Weaknesses

  • Not safe for malware. Root inside a box can remount C:. Use a full VM for anything hostile.
  • WSL2 is a hidden lightweight VM, and all boxes share one Microsoft kernel.
  • Boxes share a network and can reach your PC and local network.
  • Don't move or rename a box folder. Its path is recorded.
  • Linux Live ISOs only. Windows ISOs and installer-only ISOs won't work.
